# curly-octo-adventure

A test repository for [Claude Code](https://claude.ai/code) cloud sessions.

## Purpose

This repository exists to exercise and demonstrate Claude Code running in a
remote cloud session, rather than to host a real project. It is a convenient
place to try things out without touching anything that matters.

Typical uses:

- Verifying that a cloud session can clone the repository, commit, and push
- Trying out branch, commit, and pull request workflows end to end
- Testing CI, hooks, or repository configuration in a throwaway setting
- Scratch space for experiments and one-off examples

## What's here

Nothing but this README. The repository was created empty, and this file is its
initial commit. Any code you find here later is a test fixture, not a project
with a purpose — treat it as disposable.

## Notes

Because this is a test repository, no guarantees are made about its history.
Branches may be created and removed freely, and the contents may be reset at
any time.
